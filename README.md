# INSTALLATION
To install make sure you have git installed

To install git (on arch)
```
sudo pacman -S git
```

Then run:
```
git clone https://github.com/tembee2/nitrogen.git
cd nitrogen
sh install.sh
```
proceed to go through the installer.
